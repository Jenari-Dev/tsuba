# Japanese glossary (po/ja.po)

Use these terms everywhere so the interface reads consistently. Device and product names (BlackWidow,
Basilisk, Chroma, HyperShift...) and key caps (A, F1, Esc, Ctrl) are never translated.

| English | 日本語 | Notes |
|---|---|---|
| Profile | プロファイル | on-board profile = オンボードプロファイル |
| On-board | オンボード | stored on the device itself |
| Lighting | ライティング | |
| Lighting Studio | ライティングスタジオ | Tsuba's own effect editor |
| Game lighting | ゲームライティング | games driving the lights |
| Macro | マクロ | |
| Sensitivity (DPI) | 感度 (DPI) | "DPI" stays in Latin letters |
| Polling rate | ポーリングレート | |
| Shift layer | シフトレイヤー | Tsuba's name for the second layer |
| Standard (layer) | 標準 | |
| Customize | カスタマイズ | tab |
| Performance | パフォーマンス | tab |
| Power | 電源 | tab |
| Linked games | 連携ゲーム | |
| Assign / assignment | 割り当て | |
| Button / key | ボタン / キー | mouse = ボタン, keyboard = キー |
| Brightness | 明るさ | |
| Effect | エフェクト | |
| Colour | 色 | |
| Settings | 設定 | |
| Reset | リセット | "default" = 初期値 |
| Save / Cancel / Apply | 保存 / キャンセル / 適用 | |
| Import / Export | インポート / エクスポート | |
| Daemon / service | サービス | tsubad is "the Tsuba service" |

Style: polite plain form (です/ます) for sentences, noun phrases for buttons and labels, no full stop on
short labels, full-width punctuation (、。), a space between Latin words and Japanese text only where
the English is a name (Tsuba の設定).
